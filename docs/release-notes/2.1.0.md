# Systemd Gui 2.1.0

Systemd Gui 2.1.0 adds a dashboard, improves the Docker overview across multiple nodes and refines Quick Shell and update handling.

## Highlights

- Added a dashboard start page for local and saved remote nodes.
- Added Docker CPU and RAM totals per node and per Compose group.
- Added a combined exited-container overview across local and remote Docker nodes.
- Added update channels for stable `main` and development `dev`.
- Improved Quick Shell sequences, including multiline shell commands.

## Dashboard

- The new dashboard summarizes services, logs, Docker, nodes, Quick Shell and update state.
- Remote dashboard data loads in the background so slow nodes do not block the page.
- Dashboard tables can open the matching feature page on the selected node.
- Journal warnings, errors and critical messages from the last 24 hours are shown as fleet-level status.

## Docker

- Docker overview now shows total CPU and RAM usage per node.
- Docker Compose groups show combined CPU and RAM usage for their containers.
- Exited containers are collected into a dedicated attention section across local and remote nodes.
- Compose file paths are detected more reliably, including setups where paths are exposed through Docker working directories or bind mounts.
- Compose groups and remote nodes can be expanded or collapsed with browser-saved defaults.
- Remote Docker data loads node by node.
- Docker memory values now use clearer unit formatting, for example `2,94 MiB / 3,82 GiB`.

## Quick Shell

- Multiline sequence commands are handled more reliably, including backslash-continued commands such as longer `docker run` examples.
- Shell setup was reorganized so helper, history, timestamps, SSH and shell integration settings are easier to read.

## Updates

- Added update channels. `main` is the stable branch and `dev` is available for testing unreleased work.
- The update page warns when a system is currently on `dev`, because installing an official release switches the checkout back to `main` at the release tag.
- Remote branch updates are handled more reliably.

## Upgrade Notes

- Restart Systemd Gui after updating so Gunicorn loads the new code.
- If Quick Shell is used, run `Install / Update` in `Quick Shell > Shell setup` so `/usr/local/bin/qs` uses the latest helper code.
