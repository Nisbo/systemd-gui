# Systemd Gui 1.2.0

Systemd Gui 1.2.0 expands the project from a single-server service UI into a
small LAN-aware admin helper. The main additions are Nodes discovery, Remote
Quick Shell, better log filtering and smoother installation on existing reverse
proxy hosts.

## Nodes

- Added a Nodes page for saved servers and discovered Systemd Gui installations
  on the local network.
- Nodes can announce themselves through Avahi/mDNS and can also be saved
  manually.
- Discovery now uses IPv4-only addresses to avoid unusable IPv6 links in common
  home-server setups.
- Saved nodes show online/offline state and use a compact table layout.
- Optional SSH user, port, key path and password fields can be configured per
  node.

## Remote Quick Shell

- Quick Shell can open saved remote nodes from the `N` menu and run the remote
  server's own `qs` menu over SSH.
- Direct shortcuts are supported, for example `qs n 1`.
- Remote sessions are clearly marked with a red `REMOTE:` header.
- Per-node behavior controls whether remote `qs` stays open after commands,
  closes after one command, or asks each time.
- SSH keys are used automatically. Saved passwords work through `sshpass`, which
  can be installed from the Quick Shell setup page.
- Fresh SSH host keys are accepted automatically. Changed known host keys trigger
  a clear safety prompt before the old key is removed and the connection is
  retried.

## Logs

- Service logs and all-system logs now support journal priority filters.
- Log lines are labelled and colored by level where systemd priority data is
  available.
- Autorefresh was simplified into a single selector with an explicit off/manual
  mode.
- Added line wrapping control for easier reading of long log entries.

## Quick Shell

- Quick Shell history can include commands run through `qs` in addition to shell
  history.
- Added a shared Network quick shell template with checks, interface actions,
  DNS diagnostics, route commands and firewall helpers.
- Sequences can show readable step labels with `@ Label` lines while still
  running the command on the following line.

## Installer And Updates

- The Debian installer can detect hosts that already manage nginx or another
  reverse proxy and install Systemd Gui without forcing its own nginx site.
- The installer now includes support for Avahi discovery and `sshpass` where
  needed.
- The Nodes page can repair missing Avahi announcement setup after an update.

## Notes

- This release keeps the public port default at `8850` and the internal Gunicorn
  bind default at `127.0.0.1:8851`.
- After updating through Git, install or update the Quick Shell helper from
  `Quick Shell > Shell setup` so `/usr/local/bin/qs` uses the new code.
