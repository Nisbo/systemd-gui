# Systemd Gui 2.0.0

Systemd Gui 2.0.0 is a major update. The app is no longer only a local
systemd service UI; it now also works as a small multi-node admin dashboard
with Remote API tokens, combined logs, Quick Shell sharing and a Docker
overview.

## Highlights

- Added a token-based Remote API with separate access categories.
- Added combined journal logs across saved nodes.
- Added a Docker overview for local and remote hosts.
- Added Remote Quick Shell import/export through the API.
- Added remote Git update support for connected nodes.
- Polished the Nodes, Logs, Docker, Quick Shell and API token interfaces.

## Remote API And Nodes

- Nodes can now use Remote API tokens instead of only browser navigation and
SSH.
- Tokens are stored hashed on the server and are shown only once when created.
- Token permissions can be assigned per feature, including node info, service
details, journal logs, Docker overview, Quick Shell exports and remote updates.
- Saved nodes show compact indicators for configured SSH user, password, key
and API token.
- The node switcher now keeps the current page path when changing hosts, where
that makes sense.
- The Nodes page was split into clearer tabs for node management, local node
settings and API tokens.
- The local node settings page was redesigned and LAN discovery controls were
cleaned up.

## Logs

- The Logs page can combine journal entries from the local server and saved
remote nodes.
- Node chips show loaded and visible counts so it is easier to see which node
contributed log lines after filtering.
- Added journal time filters, including relative ranges and custom since/until
values.
- Added log search exclusion, scroll-to-top and scroll-to-bottom buttons.
- Added maximize controls for the whole log panel and for the message area.
- Added saved browser-side log view settings.
- Added appearance controls for node colors, message level colors and terminal
style black background.
- Hardened journal time filtering so old entries are filtered out even when a
remote node returns more data than expected.
- Remote log access errors are shown directly in the node chip and log output.

## Docker Overview

- Added a Docker page with local container status, image, service, CPU/RAM and
runtime information.
- Added remote Docker overview through Remote API tokens with Docker overview
permission.
- Remote Docker nodes load individually in the background so one slow node does
not block the whole page.
- Docker Compose containers are grouped by compose project.
- Compose file paths can be shown and copied where Docker exposes them.
- Local and remote Docker tables now use the same simplified layout.
- Docker image names link to likely upstream container repositories when they
can be detected reliably.
- Added browser-side controls to load local and remote compose groups collapsed
by default, plus expand/collapse actions.

## Quick Shell

- Quick Shell imports now support both local files and remote nodes through the
same preview and conflict-handling flow.
- Remote imports use the saved node token and require Quick Shell exports
permission on the remote side.
- Import previews were improved to show where entries will merge, replace or be
added.
- Placeholder help was clarified for commands like `apt search {package}`.
- API-backed Quick Shell sharing makes it easier to copy useful command
categories between Systemd Gui installations.

## Updates

- Added Remote API permission for remote updates.
- Git updates can optionally update and restart connected nodes that allow
remote updates.
- Remote update error handling is clearer when older nodes do not yet support
the API endpoint or return a non-JSON response.
- The installer now prints a detected IPv4 URL instead of a generic
`your-server` hint after installation.
- The installer root command path was fixed for systems where the installer is
started from another working directory.

## UI Polish And Fixes

- Top navigation was simplified with icon buttons and clearer active states.
- The node switcher shows version and connection indicators more compactly.
- Saved node and API token dialogs were reorganized to reduce page clutter.
- Docker and log controls were aligned and made more compact.
- Dark mode and terminal log color handling were fixed so colors can be fully
disabled.
- Several table layouts were tightened for smaller screens such as laptops.

## Upgrade Notes

- After updating, restart Systemd Gui so the running Gunicorn process loads the
new code.
- If Quick Shell is installed, open `Quick Shell > Shell setup` and run
`Install/update helper` so `/usr/local/bin/qs` uses the new code.
- If LAN discovery is used, check `Nodes > This node` and repair/install LAN
discovery if the page reports it as missing.
- Remote logs, Docker overview and remote updates require new token
permissions. Existing tokens may need to be edited or regenerated with the
needed access categories.
